- Skeleton: constants complete; `applyManagedBlock` throws `contract stub C4`.
- `applyManagedBlock` (M3 round-trip invariant): EOL = style of the first `\n` (CRLF if preceded by `\r`), LF when none. Block = START, entries, END, each + EOL. Lines compare without trailing `\r`; line 0 ignores a leading U+FEFF (kept). START…END (END's terminator included) present → replace in place. No START → `t + block`, appending one EOL first when `t` is non-empty and does not end with `\n`. START without END → throw `WikeeperError(ExitCode.ERROR, "gitignore_malformed", ".gitignore has a wikeeper start marker without an end marker; fix it and re-run")`.
- `managedIgnoreEntries` (fixed order, posix, root-relative via `toPosixRelative`): `.wiki/me.md`, `.wiki/.lock`, `.wiki/.snapshots/`, `.wiki/.cache/`, `<content>/log.md`, then each `private` page as `<content>/pages/<p>` (deduped, code-unit sorted). A `private` value that resolves outside `pagesDir` is skipped with warning `private entry "<p>" is outside pages/; not ignored`. An entry with no `/` gets a leading `/` (only for `content_dir: "."`); a leading `#` or `!` gets a `\` prefix.

### STORY-001-04 — `wikeeper init` (owns C4)
STORY-001-04 advances the goal by producing the `.wiki/` tree, manifest and `.gitignore` block for Goal check 1, a byte-stable re-run for Goal check 2, and the hook point that wires every agent.
- **Files:** `src/commands/init.ts`, `src/core/integrations.ts`, `src/core/gitignore.ts`, `templates/kb_instructions.management.md`, `templates/index.md`, `test/init.test.ts`, `test/gitignore.test.ts` (all new); `src/program.ts`. QA-Red: `test/init.red.node.test.ts`.
- **`src/program.ts`:** `import { initCommand } from "./commands/init.js";` in the import region; `  initCommand,` as the last element of `defaultCommands`.
- **Exports (`init.ts`):**
```ts
export const PROFILES = ["management"] as const;
export interface InitResult { created: string[]; updated: string[]; skipped: string[]; manifest: string } // manifest = ".wiki/system/manifest.json"
export interface InitDeps { templatesDir?: string; packageVersion?: string }
export function runInit(root: string, run: Pick<IntegrationOptions, "flags" | "json" | "interactive" | "io">, deps?: InitDeps): Promise<InitResult>;
export function createInitCommand(deps?: InitDeps): CommandModule;
export const initCommand: CommandModule = createInitCommand();
```
  Options: `--profile <name>` (default `management`), `--agents <list>`, `--yes`, `--enforce`. `updated` is additive to R8: files whose bytes changed (a system file restored to the template, `.gitignore` gaining or refreshing its block, the manifest) plus the integrations' `replaced`.
- **Layout produced** (default `content_dir: .wiki`; architecture §4/§6.3; `me.md` and `log.md` are never created):
```
.gitignore                         managed block (file created if missing)
.wiki/config.yml                   seeded if missing  (user)
.wiki/kb_instructions.md           seeded if missing  (user; templates/kb_instructions.<profile>.md)
.wiki/system/<every templates/system/** file>   package (today SETUP.md, WIKI.md; EPIC-006 adds profiles/, templates/)
.wiki/system/manifest.json
<content>/index.md                 seeded if missing  (templates/index.md)
<content>/raw/.gitkeep  <content>/pages/.gitkeep  <content>/log/.gitkeep   empty, created if missing
```
  With `content_dir: wiki`, `index.md`, `raw/`, `pages/` and `log/` go under `wiki/`; `config.yml`, `kb_instructions.md` and `system/` stay in `.wiki/`.
- **Algorithm.** Steps 1–5 are a pre-pass: no error after step 5 can come from validation.
  1. `opts.profile ∉ PROFILES` → `WikeeperError(USAGE, "usage", 'unknown profile "<p>"; available profiles: management', { available: ["management"] })`, before any fs call.
  2. `root = findRepoRoot(ctx.cwd)`; `{ config, warnings, errors } = await loadConfig(root)`. `E_CONFIG_SYNTAX` propagates. `errors.length > 0` → `WikeeperError(ERROR, "config_invalid", ".wiki/config.yml is invalid: " + errors.map(formatConfigIssue).join("; "))`. Each warning becomes an output warning via `formatConfigIssue`.
  3. `paths = resolvePaths(root, config)`; `old = await readManifest(paths.manifestFile)` (`E_MANIFEST_INVALID` propagates, exit 1); `packageVersion = deps.packageVersion ?? readPackageVersion()`, where `readPackageVersion` is a private helper that reads `<findPackageRoot()>/package.json`. Never import `VERSION` from `program.ts` (M3: import cycle and TDZ).
  4. `tpl = await listTemplateFiles("system", templatesDir)`; `system/<rest>` maps to `.wiki/system/<rest>` (posix) and `path.join(paths.systemDir, ...rest.split("/"))`. Throw if a destination equals `paths.manifestFile`. `lstat` each destination: if it exists and is not a regular file → `WikeeperError(ERROR, "unsafe_path", "<rel> is not a regular file")`.
  5. Read `.gitignore` (ENOENT → `""`, `existedBefore = false`). Decode with `TextDecoder("utf-8", { fatal: true, ignoreBOM: true })`; invalid UTF-8 → `WikeeperError(ERROR, "gitignore_not_utf8", …)`. `next = applyManagedBlock(text, managedIgnoreEntries(paths, config).entries)`. A malformed block throws here.
  6. Copy each template via `copyTemplate(rel, dest, templatesDir)`. `written` and the destination was absent → `created`; `written` and it existed → `updated`; otherwise `skipped`. The entry is `{ path, sha256: result.sha256, kind: "system" }`.
  7. Seed when `lstat` gives ENOENT, else add to `skipped` (never write through a link):
     - `config.yml`: exactly `# wikeeper configuration (user-owned). Missing keys use built-in defaults.\nprofile: <profile>\nagents: []\n` (002-04 saves the resolved agents via `setConfigValue`, which skips an equal value). `kb_instructions.md`, `index.md`: `copyTemplate`. Each content dir: `mkdir -p` plus an empty `.gitkeep`.
  8. Write `.gitignore` only if `next !== text` (bytes). Gitignore entry: `{ path: ".gitignore", sha256: null, kind: "gitignore", created: oldEntry?.created ?? !existedBefore }`. **Keep `created` from the old manifest**, or a second run flips it, changes the manifest bytes and breaks 001-06's delete-if-created.
  9. Working manifest:
     - Start from `old ?? { package_version, files: [] }`; replace the `system` entries for current template paths and the `gitignore` entry with the fresh ones. Old `system` entries for paths no longer shipped stay (update removes them); integration kinds and `file` entries are untouched.
     - Set `package_version`, then `await writeManifest(...)`, so the disk describes the scaffold even if a handler throws next.
  10. `r = await runIntegrations("init", { root, paths, config, options: { flags: opts, json, interactive, io, manifest: working, templatesDir, packageVersion } })`, then `writeManifest` again (skipped when identical). Merge `r.created → created`, `r.replaced → updated`, `r.skipped → skipped`, `r.warnings → warnings`. Add the manifest to `created` when it was absent at step 3, or to `updated` when its bytes changed.
  11. Sort every list (code-unit order) and call `emitResult(ctx, { command: "init", data, warnings, message })`. The message is `initialised .wiki/: <c> created, <u> updated, <s> unchanged` plus `next: ask your agent to read .wiki/system/SETUP.md`. When nothing changed it is `already initialised: nothing changed`.
- **Idempotency (R7):** every write is skip-if-identical (`copyTemplate`, the `.gitignore` compare, `writeManifest`), the seeds are create-only, there are no timestamps, entry order is fixed, and `created` is kept. A second run therefore leaves `created` and `updated` empty.
- **Interactive vs `--yes`/`--json`, exit 5:** core init never prompts. `interactive` (C4 ADD) is passed to the handlers. In M4, 002-04 turns a `needs_input` result into `throw needsInputError(r)`. The throw propagates out of `runIntegrations` and `emitError` maps it to exit 5 with `error.details = { choices, files }`. Core files from steps 6–9 stay on disk (re-run safe); see open decision 2.
- **Placeholders** (LF, trailing newline, line 1 `<!-- placeholder: real text arrives in EPIC-006 -->`):
  - `kb_instructions.management.md`: `# Knowledge Base Instructions`, `purpose: management`, then the §5.2 headings, each with an empty body (Questions, Entities, Capture signals, Source kinds, Write policy, Never capture, Rule changelog).
  - `index.md`: `# Wiki index` and `_No pages yet._`.
- **Red scenarios (`test/init.red.node.test.ts`):**
  - Setup: `beforeEach(resetIntegrations)`; temp repo `mkdtemp(path.join(os.tmpdir(), "wikeeper-init-"))` with `.git/`; `runCli([...], { commands: [createInitCommand()], io: { cwd: root, stdout, stderr, stdin: Readable.from([]) } })`, real templates.
  1. Fresh repo: the layout above. Manifest `system` entries equal the set of files under `.wiki/system/` minus `manifest.json`, with hashes from `createHash`. `.gitignore` contains START…END. A registered `{ name: "test", init: vi.fn() }` is called once with `ctx.paths.systemDir === path.join(root, ".wiki", "system")`. `created` equals every file in the tree outside `.git/`. Do not assert the total `manifest.files.length`: it also holds the `gitignore` entry.
  2. Idempotent: hash the whole tree, run `init --yes --json` again → hashes equal, `created: []`.
  3. User files: custom `kb_instructions.md` is byte-identical. A `.gitignore` of `"node_modules/\n"` still starts with `node_modules/` and has exactly one START line.
  4. `content_dir: wiki` plus `private: [team.md]`: `wiki/{raw,pages,log}/.gitkeep` and `wiki/index.md` exist, `.wiki/system/` exists, and the block has the lines `wiki/log.md` and `wiki/pages/team.md`.

### STORY-002-02 — Agent detection and target files (owns C6)
STORY-002-02 advances the goal by choosing which agent files get the WIKI block: never `CLAUDE.md` unless it exists (D-32), and `AGENTS.md` when no file exists (D-12). That decides the "no CLAUDE.md is created / no byte outside the markers changes" half of Goal check 1.
- **Files:** `src/agents/detect.ts` (C6 above), `src/agents/ask-agents.ts`, `test/agents/detect.test.ts`. QA-Red: `test/agents/detect.red.node.test.ts`.
- **`ask-agents.ts`** (not a contract; 002-04 and 002-06 consume it):
```ts
export interface LineReader { nextLine(): Promise<string | null>; close(): void }       // null = EOF
export function createLineReader(stdin: NodeJS.ReadableStream): LineReader;            // ONE per command run
export function parseAgentSelection(answer: string, choices: readonly AgentName[], preselected: readonly AgentName[]): AgentName[] | null;
export function createAskAgents(io: { stderr: TextSink; lines: LineReader }): AskAgents;
```
  - `createLineReader`: `createInterface({ input: stdin, terminal: false })` (`node:readline`) with one `rl[Symbol.asyncIterator]()`.
  - Prompt on stderr: `Which agents do you use? (numbers or names, comma-separated; Enter = marked)`, lines `  1) [x] claude`…, then `> `. Parsing: `""` → `preselected` (or `null` if empty); `1,2` / `claude, codex` → canonical, deduped; else `null`. `null` re-prompts (3 attempts total); then, or on EOF, return `[]`.
- **Algorithm:**
  - `detectAgentFiles`: `readdir(root)`, keep exact names in `AGENT_FILES`, keep only those where `stat` (follows links) gives `isFile()`, return in canonical order. Never `existsSync("CLAUDE.md")`: on case-insensitive macOS/Windows it matches `claude.md`.
  - `readersOf(f, existing)`: `always`, plus `whenAbsent.agents` when `!existing.includes(whenAbsent.file)`.
  - `resolveTargets`: each existing file whose readers intersect `agents` → `{ path, create: false }`; if any agent reads no existing file, add `{ path: "AGENTS.md", create: true }` (only possible when `AGENTS.md` is absent). Canonical order; empty `agents` → `[]`.
  - `parseAgentList`: split on `,`, trim, drop empties, dedupe, canonical order. Unknown → `WikeeperError(USAGE, "usage", 'unknown agent "cursor" in --agents; allowed: claude, codex, antigravity', { unknown, allowed: AGENT_NAMES })` (origin text varies); empty → usage error `no agents given in --agents`.
  - `resolveAgents`:
    - `flag !== undefined` → `{ status: "resolved", agents: parseAgentList(flag, "--agents"), source: "flag" }`.
    - Else if `config.agents.length > 0` → `source: "config"`; validate with `parseAgentList(config.agents, "config agents")`.
    - Else if `isTTY && !json` → `ask({ choices: [...AGENT_NAMES], preselected, files: existing })`, where `preselected` = `existing.map(f => PRESELECT_BY_FILE[f])` deduped in canonical order. A non-empty answer → `source: "prompt"`; `[]` → `needs_input`.
    - Otherwise → `{ status: "needs_input", choices: [...AGENT_NAMES], files: [...existing], message: "no agents configured: re-run with --agents <list> (choices: claude, codex, antigravity)" }`.
  - `needsInputError(r)` returns `new WikeeperError(ExitCode.NEEDS_INPUT, "needs_input", r.message, { choices: r.choices, files: r.files })`.
- **Red scenarios:**
  1. Outline over the 6 rows: build the files in a temp dir, `detectAgentFiles`, then `resolveTargets`; compare `{ path, create }[]`.
  2. `flag: "codex"`, config `["claude"]` → `["codex"]`, `source: "flag"`, `ask` not called.

```ts
export const GUARD_REASON = "Wiki pages can only change during an ingest. Run `wikeeper ingest apply <id>` first — see .wiki/system/WIKI.md."; // U+2014
export interface HookResponse { stdout?: string; stderr?: string; exitCode: 0 | 2 }
export interface GuardTargets { cwd: string; paths: string[] }            // paths as given; [] = tool not guarded → allow
export interface HookAdapter {
  readonly agent: AgentName; readonly tools: readonly string[];
  targets(payload: unknown, fallbackCwd: string): GuardTargets | null;    // null = unreadable (R6)
  allow(): HookResponse; deny(reason: string): HookResponse;
}
export const HOOK_ADAPTERS: Readonly<Record<AgentName, HookAdapter>>;
export function parsePatchPaths(patch: string): string[];
export function resolveTarget(cwd: string, p: string): string;           // path.resolve(cwd, p.replace(/\\/g, "/"))
export function isInside(parent: string, child: string): boolean;        // path.relative rule (M3), rel "" counts as outside
export function failOpen(agent: AgentName | undefined, detail: string): HookResponse;
```
  `targets` returns `{ cwd, paths }` instead of §3.2's bare `string[]`: the adapter also owns where the working directory comes from.

  | | Claude | Codex | Antigravity |
  |---|---|---|---|
  | tools | `Edit`, `Write`, `MultiEdit`, `NotebookEdit` | `apply_patch` (`Bash` = accepted gap → `[]`) | `write_to_file`, `replace_file_content`, `multi_replace_file_content` |
  | `null` when | not an object; `tool_name` not a string; `tool_input` not an object; path not a non-empty string | `tool_input.command` not a string | `toolCall` / `toolCall.name` / `toolCall.args` missing; `args.TargetFile` not a string |
  | path | `tool_input.file_path`, or `tool_input.notebook_path` for NotebookEdit | `parsePatchPaths(tool_input.command)` | `toolCall.args.TargetFile` |
  | cwd | `payload.cwd` if a string, else fallback | same | `workspacePaths[0]` if a string, else fallback |
  | allow | no output, exit 0 | no output, exit 0 | stdout `{"decision":"allow"}\n`, exit 0 |
  | deny | stdout `{"hookSpecificOutput":{"hookEventName":"PreToolUse","permissionDecision":"deny","permissionDecisionReason":R}}\n`, exit 0 | stderr `R\n`, exit 2 | stdout `{"decision":"deny","reason":R}\n`, exit 0 |

  `parsePatchPaths`: per line of `split(/\r?\n/)`, match `/^\s*\*\*\* (?:Add File|Update File|Delete File|Move to): (.*)$/`, trim, drop empties, dedupe.

  `failOpen(agent, d)`: stderr `warning: wikeeper hook guard allowed the write: <d with newlines collapsed>\n`, exactly one line. For antigravity, also stdout `{"decision":"allow"}\n`.
- **`hook.ts`:**
  - Exports `GuardInput { agent: string | undefined; stdin: NodeJS.ReadableStream; isTTY: boolean; cwd: string }`, `runGuard(input): Promise<HookResponse>` (never throws), `readPayload(stream, max): Promise<string | null>` and `hookCommand: CommandModule`.

  1. An unknown agent → `failOpen(undefined, 'unknown --agent "<a>"')`.
