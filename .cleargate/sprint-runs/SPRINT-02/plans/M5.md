- **Cross-story coupling:** writes below 004-04's code (`sinceBound`, `renderSearch`); `log/` events are read by 004-04's `--since` (type-filtered to `ingest`, so misses never leak into `changes`) and written during 003-09's write phases (new files, allowed by `finish`).
- **Exports of `src/search/misses.ts`:**
  - Frozen by story §3.3: `shouldRecordMiss`, `encodeMissFilters`, `decodeMissFilters`, `recordMiss`, `summarizeMisses`.
  - Additive (Open decision 2): `listMisses(paths: ResolvedPaths, bound: SinceBound | null): Promise<MissSummary[]>` and `renderMisses(data: SearchData): string`.
- **Decisions:**
  - **`shouldRecordMiss(data)`** = `data.mode !== "misses" && data.total === 0`. This covers query, filter-only, `--since`-only (004-04's `total` = facts + page entries) and entity mode (`total` 0 when not found).
  - **`encodeMissFilters(filters, entity)`**, keys in this order and only when set: `type` (string), `where` (`["<key>=<value>", …]`), `status`, `since`, `entity`.
  - **`decodeMissFilters(raw)`** → `{ filters: { type, where, status, since }, entity }`:
    - scalar keys (`type`, `status`, `since`, `entity`): a string as is; a list → its items joined with `", "`;
    - `where`: a string is a one-item list; each item splits at the first `=` into trimmed `key` / `value`; an item without `=` → `{ key: item.trim(), value: "" }`;
    - unknown keys are ignored.
  - **`recordMiss(paths, data, now)`:** `writeLogEvent(paths, { type: "miss", at: now.toISOString(), query: data.query ?? "", filters: encodeMissFilters(data.filters, data.entity_query) })` inside `try`. On any error: `{ logged: false, warning: \`miss not logged: ${toPosixRelative(paths.root, paths.logDir)}: ${err.code ?? err.message}\` }`. Never rethrow; no lock check (R2).
  - **`summarizeMisses(events)`:**
    - Skip an event unless `event.type === "miss"`, `query` is a string, and `filters` is a plain object whose every value is a string or an array of strings.
    - `nq = normalizeName(query)`, `null` when `""`; `ne = entity === null ? null : normalizeName(entity)` after decoding.
    - Group key `JSON.stringify([nq, { type, where, status, since }, ne])` (canonical key order, §3.2).
    - Per group: the representative is the event with the smallest `Date.parse(at)` (ties: input order). `query` = its query as recorded (`null` when `nq` is `null`), `filters` and `entity` decoded from it; `count`; `first_at` / `last_at` = the stored `at` strings of the earliest / latest event.
    - Sort: `count` descending; `Date.parse(last_at)` descending; `nq` by `compareCodeUnits` with `null` last; then the group key.
  - **`listMisses(paths, bound)`** = `summarizeMisses((await readLogEvents(paths, bound === null ? { type: "miss" } : { type: "miss", since: bound.instant })).events)`. `skipped` files are ignored (R3).
  - **`renderMisses(data)`** (R6):
    - `data.total === 0` → `no recorded misses`;
    - otherwise the header `${n} recorded ${n === 1 ? "miss" : "misses"}` with `n = data.total`, then one line per entry of `data.misses` (already capped):
      `` `${count}×` `` + (`query !== null` ? `` ` "${query}"` `` : "") + (`describeFilters(filters)` when non-empty, after a space) + (`entity !== null` ? `` ` entity ${entity}` `` : "") + `` ` (last ${new Date(Date.parse(last_at)).toISOString().slice(0, 10)})` ``.
    - `×` is U+00D7. Example: `2× "budget burn" (last 2026-10-12)`, `1× entity Nobody (last 2026-10-13)`.
  - **N2 block** (below line 214):
    ```ts
      if (req.misses) {
        missesUsage(req);
        const misses = await listMisses(paths, sinceBound);
        data = {
          ...data,
          mode: "misses",
          query: null,
          entity_query: null,
          total: misses.length,
          results: [],
          entity: null,
          changes: null,
          misses: misses.slice(0, req.limit),
        };
      }
      if (shouldRecordMiss(data)) {
        const miss = await recordMiss(paths, data, (deps.now ?? (() => new Date()))());
        if (miss.warning !== null) warnings.push(miss.warning);
    ```
