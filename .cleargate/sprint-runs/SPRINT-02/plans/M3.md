  - the not-initialised block of `src/commands/setup.ts:28-37`, with its message `wiki is not initialised: run wikeeper init`.
- **`planDirectory(paths, config, dirAbs, { kind })` decisions:**
  1. **`dir`.** `dirAbs === paths.root ? "." : fileOrigin(paths.root, dirAbs)`. `fileOrigin` returns an absolute path for the root itself, because `isInside` is strict (`src/core/paths.ts:66-69`).
  2. **Root inside the wiki.** When `dirAbs` equals or is inside `paths.wikiDir` or `paths.contentDir`, return `entries: []`, `skipped: [{ path: dir, reason: "wiki" }]` and all-zero totals. This is not a usage error: R1 lists the usage errors exhaustively (Open decision 5).
  3. **Walk.** Recursive `readdir(d, { withFileTypes: true })`. For each entry, `abs = path.join(d, e.name)`, checked in this order:
     - **wiki:** `abs === paths.wikiDir || abs === paths.contentDir || isInside(paths.wikiDir, abs) || isInside(paths.contentDir, abs)` → skip `{ path: fileOrigin(root, abs), reason: "wiki" }` and do not descend. The equality checks are required: the walk meets the content directory itself (Gherkin `docs/wiki`), and `isInside(x, x)` is false.
     - **symlink:** `e.isSymbolicLink()` → skip `"symlink"`, never followed or stat'ed.
     - **hidden:** `e.name.startsWith(".")` → skip `"hidden"`. This covers files and directories; a hidden directory is listed once and not descended.
     - directory → recurse; regular file → candidate.
     - anything else (FIFO, socket, device) → ignored and not listed: `hashSource` would block on a FIFO.
     - **The hidden rule applies only to names below `<dir>`, never to segments of `<dir>` itself.** The walkthrough plans a directory under `~/product_repo/.cleargate/wiki/`.
  4. **Sort.** Candidates by `fileOrigin` (`compareCodeUnits`); `skipped` by `path`.
  5. **Sources.** `listSources(paths)` once per plan.
  6. **Per candidate, in sorted order.** Compute `{ sha256, size } = await hashSource({ originalPath: abs, text: null })` and `origin = fileOrigin(root, abs)`, then:
     - **registered duplicate:** `findDuplicate(sources, { sha256, originType: "file", origin })` → `status: "duplicate"`, `prior: { id, captured_at, match: "sha256" }`, `reason: "already ingested as <id>"`. For files, `findDuplicate` matches only by sha256 (`registry.ts:91-97`).
     - **in-plan duplicate:** else `firstNew.get(sha256)` → `status: "duplicate"`, `prior: { path, match: "in_plan" }`, `reason: "same content as <path>, earlier in this plan"`.
     - **otherwise:** `r = evaluatePermission(config.ingest, { origin, originType: "file", kind, approved: false })`.
       - `denied` → `status: "denied"`.
       - `allowed` / `needs_approval` → `status: "new"`, `needs_approval: r.decision === "needs_approval"`, `kind_pending: r.kind_pending`, and record `firstNew.set(sha256, origin)`.
       - Every such entry has `reason: r.reason`. Only `new` entries enter `firstNew` (Open decision 5a).
     - Duplicates have `needs_approval: false` and `kind_pending: false`. Denied entries have `needs_approval: false` and `kind_pending: r.kind_pending`, which is always false on a denial (`permissions.ts:143-150`).
  7. **Result.** `mode: config.ingest.permission`, `kind`, `totals` counted from `entries`. No writes and no hooks.
- **Command (`src/commands/ingest-plan.ts`):**
  - **Registration:** `group.command("plan").description("list which files of a directory are new, duplicates or denied; stores nothing").argument("<dir>", "directory to plan").option("--kind <kind>", "source kind for every file, as listed in .wiki/kb_instructions.md")`.
  - **Action order**, every error thrown inside the action (flashcard #cli #commander):
    1. config and paths; `stat(paths.configFile)` fails with ENOENT → `WikeeperError(ExitCode.ERROR, "not_initialised", "wiki is not initialised: run wikeeper init")`;
    2. `dirAbs = path.resolve(ctx.cwd, dir)`, then `stat`:

- **Decisions:**
  - **`hasFilters`** = `type !== null || where.length > 0 || status !== null`, **without `since`**. 004-04 R8 needs `--since` alone to give `results: []`.
  - **`parseWhere(raw)`:**
    - split at the first `=` and trim both sides;
    - no `=`, an empty key or an empty value → `WikeeperError(ExitCode.USAGE, "invalid_filter", "--where needs key=value, got \"<raw>\"", { expected: "key=value", got: raw })`.
  - **`parseFilterValue`:**
    - `undefined` → `null`;
    - `raw.trim() === ""` → `invalid_filter`, `"<flag> needs a non-empty value"`, `{ expected: "a non-empty value", got: raw }`;
    - otherwise `raw.trim()`.
    - Compare with `!== undefined`, never by truthiness: commander passes `--type ""` through as `""`.
  - **Tokens:** `tokens(s) = normalizeName(s).split(" ").filter(Boolean)`. A value matches a candidate when every token of the value is a whole token of the candidate.
  - **Candidates for key `k` (lowercased):**
    - the entity's own `typedLinks` with `key === k` (the parser lowercases keys, `parse-page.ts:323`): each `targets` element, or `value` when `targets` is empty;
    - for page entities only, also every `page.frontmatter.data` key whose `toLowerCase()` is `k` (`data` is the whole frontmatter mapping, `parse-page.ts:170`): a string → itself, a number or boolean → `String(v)`, an array → each string, number or boolean element; anything else contributes nothing.
    - No `[[…]]` unwrapping of frontmatter strings (out of spec).
  - **`matchesFilters` (AND):**
    - `type`: `entity.type !== null && normalizeName(entity.type) === normalizeName(type)`. A page entity's type is the raw frontmatter `type`; a section entity's is its lowercased `type::` value (`parse-page.ts:417`).
    - every `where`;
    - `status`: some `status` candidate (same candidate rule) is `normalizeName`-equal.
  - **`entityHit`:**
    - `path` = `entity.path`;
    - `file` = `toPosixRelative(root, path.join(paths.pagesDir, ...entity.path.split("/")))`;
    - `title` = `page.title`; `entity` = `entity.name`; `type` = `entity.type`;
    - `section` = `page.sections[entity.section].heading`, which is `""` for a page entity (section 0); `line` = `entity.line`; `score` = 0;
    - `snippet` = `(entity.summary ?? first non-empty trimmed line of page.sections[entity.section].text ?? "")` with whitespace collapsed, then `.slice(0, 160)` (R5: "cut to 160 characters", no `…`);
    - `sources` = `hitSources(page, entity.section)`.
  - **`describeFilters`:** `--type <t>`, `--where <k>=<v>` per entry, `--status <s>`, `--since <d>`, joined by spaces and only for the fields that are set.
