    No local `--json`.

    Action order:
    1. `source === undefined` → usage error. `source === "-"` → usage error. Both are `WikeeperError(ExitCode.USAGE, "usage", …)`, so the envelope names `read` (FLASHCARD `#cli #commander`).
    2. If `opts.out !== undefined`, check it (R8) before anything is read: `abs = path.resolve(ctx.cwd, out)`. The checks run in R8's order, each a usage error with its own message:
       1. the path exists (`lstat` succeeds);
       2. the parent directory is missing or not a directory;
       3. `path.extname(abs).toLowerCase()` is not `.md` or `.txt`;
       4. `path.basename(abs).toLowerCase()` is `agents.md`, `claude.md` or `gemini.md`;
       5. `path.relative(ctx.cwd, abs).split(path.sep).some((s) => s.startsWith(".") && s !== "..")`;
       6. the content-dir check: `root = findRepoRoot(ctx.cwd)` (`src/core/paths.ts:26`), then `loadConfig(root)` (on a throw, use `DEFAULT_CONFIG`), then `resolvePaths`. Refuse when `isInside(paths.contentDir, abs)` (`:69`) or `abs === paths.contentDir`.
    3. `const r = await readSource(source, { cwd: ctx.cwd, ...deps })`.
    4. With `--out`: `writeFile(abs, r.markdown + "\n", { flag: "wx" })`. An `EEXIST` becomes the same usage error as check 2.1.
    5. Output:
       - **`--json`:** `emitResult(ctx, { command: "read", data, warnings: r.warnings.map((w) => w.message) })`, with `data = { ...r, ...(out ? { out: abs } : {}) }`.
       - **Human, no `--out`:** the same call with `message: r.markdown`, so stdout is the markdown plus `\n`.
       - **Human, with `--out`:** `message: \`wrote ${opts.out} (${Buffer.byteLength(r.markdown + "\n")} bytes, ${r.format})\``.
       - Warnings go to stderr (`src/core/output.ts:107`).

      - Any other `null` format → `WikeeperError(ExitCode.USAGE, "unsupported", \`cannot read ${what}: read takes web pages and .html, .htm, .md, .markdown, .txt, .csv, .tsv, .docx and .pdf files\`)`, where `what` is the extension, or the content type for a URL.
    - **Branches:**

      - A CSV or TSV source passes through like `.txt` (R3).

        - `keepsTitle`: the first heading, then `meta` if any, then the rest of the body.
        - Otherwise: `# ${c.title}` when a title is known, then `meta` if any, then the body.
