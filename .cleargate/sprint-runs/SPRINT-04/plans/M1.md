- **`estimateTokens` (R1).** Step 1: `text.replace(/([^\sA-Za-z0-9Ⴀ-ჿЀ-ӿ])\1{2,}/g, () => { runs++; return ""; })` — no `u` flag (the escaped ranges are the reference's `Ⴀ-ჿ` and `Ѐ-ӿ`). Step 2: one `charCodeAt` loop, integer hundredths: a whitespace code unit (`\t \n \v \f \r`, space, U+00A0, U+1680, U+2000–U+200A, U+2028, U+2029, U+202F, U+205F, U+3000, U+FEFF) adds 51 only when the previous unit was not whitespace; A–Z/a–z 32; 0–9 62; any other unit < 128 88; U+0400–U+04FF 37; U+10A0–U+10FF 74; else 38, where a high surrogate followed by a low surrogate is consumed as one unit, and a lone surrogate counts once. Add `30 × runs`. Return `Math.round(sum / 100)` (ties are exact `.5` values, so they round up). No per-character regex or string.
- **`formatTokens` / `formatLimit` (R2).** Integer arithmetic only (no `toFixed`): `n = Math.round(n)`; negative → `"≈-" + formatTokens(-n).slice(1)`; `< 1000` → `≈n`; `t = Math.round(n/100)`, `t < 100` → `≈${⌊t/10⌋}` + (`t%10 ?
