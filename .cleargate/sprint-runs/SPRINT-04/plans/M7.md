## §3. How `init` and `update` treat the files

**System files (SETUP.md, ONBOARDING.md, WIKI.md).**
- `init` copies every `templates/system/**` file (`src/commands/init.ts:94–100`, loop `:165–180`) with `copyTemplate`, which writes when the bytes differ (`src/core/templates.ts:80–105`). It records each file's sha256 in the manifest as `kind: "system"`.
- `update` lists the template's `system` files (`src/commands/update.ts:83–90`). For each one, in the loop at `:127–153`:
  1. it skips the file when the installed copy already has the new hash (`:149`);
  2. it backs up a locally edited copy, whose hash differs from the manifest entry (`:150`);
  3. it then copies the template, and lists the file in `replaced`.

  New manifest entries come from the template bytes at runtime (`:128–131`, `:177–180`).
