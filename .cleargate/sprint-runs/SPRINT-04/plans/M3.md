`snapshotFacts` reads `path.join(snapshotDir(paths, sourceId), tree, ...rel.split("/"))`, returns `{ facts: parsePage(text, rel).facts, lines: stripBom(text).split(/\r?\n/) }`, and on any read error throws `WikeeperError(ExitCode.ERROR, "snapshot_missing", `the snapshot copy of ${label} is missing or unreadable (${toPosixRelative(paths.root, file)}): run wikeeper ingest abort ${sourceId}`)` with `label = tree === "archive" ? `archive/${rel}` : rel` (today's text at `src/ingest/validate.ts:63–67`, generalised).

**Logic (`validateIngest`, in this order; `const arch = diff.archive ?? { created: [], updated: [], deleted: [] }`):**
1. Created ∪ updated live `.md` pages (today's loop, `:53`). For an updated page, missing keys = snapshot keys (deduped with `seen`, as `:71–76`) not in `keysOf(page)`. Only when some are missing, read `archive/<rel>` (`ENOENT` → empty set; other errors rethrow); each missing key: held → `archived.facts += 1`; not held → `dropped`. Frontmatter and citation checks unchanged (`:79–84`).
2. Deleted live `.md` pages. If any: `live = union of keysOf over loadPages(paths.pagesDir)`, `kept = union over loadPages(paths.archiveDir)` (missing folder → `[]`, `src/wiki/parse-page.ts:432`), built once. Per deleted page: `snapshotFacts(…, "pages", rel)`, distinct keys in snapshot order: in `live` → nothing; else in `kept` → `archived.facts += 1`; else → `dropped { path: rel, line }`. Then `archived.pages += 1` when `arch.created` or `arch.updated` includes `rel`.
3. `arch.created ∪ arch.updated` `.md`: parse from `paths.archiveDir`; `FRONTMATTER_CODES` errors → `invalid { path: "archive/" + rel, message: frontmatterMessage(e) }`. No `citesSource`.
4. `arch.updated` `.md`: snapshot keys missing now → `archived_dropped`. `arch.deleted` `.md`: every snapshot fact → `archived_dropped`; none → one `{ path: rel, line: "" }`.
5. Sorts: `dropped` and `archived_dropped` stable by path (`compareCodeUnits`), snapshot order within a page; `invalid` as today (one combined stable sort, `:88`). `ok` adds `archived_dropped.length === 0`. The `sources/<id>.md is missing` warning is unchanged (`:91–97`, `pages/` only).

**`ingest finish` (`src/commands/ingest-finish.ts`):**
